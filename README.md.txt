# Student Management System (Python)

## Description
A beginner-friendly console-based Python project to manage student records, calculate average marks, and identify the topper.

## Features
- Add student details
- Store marks securely
- Calculate average marks
- Find top-performing student
- Input validation for marks

## Technologies Used
- Python (core concepts only, no external libraries)

## Learning Outcomes
- Practiced lists and dictionaries
- Used functions, loops, and conditionals
- Improved logical thinking and error handling

## How to Run
```bash
python student_management.py
